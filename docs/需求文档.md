# 词网探索 — 产品需求文档

## 1. 项目概述

### 1.1 背景
传统关键词研究工具往往单向输出，用户无法交互式地探索语义网络。本项目旨在打造一个 **LLM 驱动的交互式语义探索工具**，让用户通过"种子词 → 关联词 → 精选手动探索"的循环，直观地发现概念之间的语义关联，并基于中央词生成短文。

### 1.2 目标
- 提供流畅的、可迭代的语义关联探索体验
- 支持多轮探索，用户可随时调整方向
- 基于中央词生成高质量短文
- 支持中英双语界面
- 支持集合管理，复用探索成果

## 2. 用户角色

| 角色 | 描述 |
|------|------|
| 普通用户 | 使用本工具进行关键词探索和文章生成 |
| 研究者/写作者 | 需要拓展思路、发现关联概念的知识工作者 |

## 3. 功能需求

### F1: 种子词探索
- 用户输入一个种子词，点击"探索"
- 调用 LLM 返回 20 个语义关联词
- 关联词以卡片网格展示

### F2: 多轮迭代探索
- 用户点击/悬停选中关联词（可多选）
- 点击"探索选中"，选中词移入中央区，LLM 返回下一批 20 个关联词
- 未选中任何词时，默认使用当前全部词继续探索
- 顶部面包屑记录探索路径，支持回溯

### F3: 中央词管理
- 中央区展示所有已探索/手动添加的词
- 点击词的 ✕ 按钮手动移除
- 可通过输入框手动添加自定义词
- 中央词会累积，不会自动消失

### F4: 悬停自动选中（可配置）
- 鼠标悬停词卡 500ms 自动选中/取消选中
- 可在设置面板中关闭此功能

### F5: 集合管理
- 将当前中央区的词保存为集合（命名、编辑、删除）
- 集合展示在左侧边栏
- 可勾选集合，勾选后其词自动参与 LLM 种子（不显示在中央区）
- 集合可展开，查看/删除内部词，手动添加新词
- 集合数据持久化在 localStorage

### F6: 文章生成
- 基于中央词 + 已勾选集合的词，调用 LLM 生成短文
- LLM 将选中词作为高维语义方向，而非强制使用每个词
- 生成的短文以 Markdown 渲染
- 支持一键复制 Markdown 原文

### F7: 文章续写
- 点击"续写"按钮，LLM 基于原文和种子词继续写作
- 新内容追加到原文末尾

### F8: 文本提取关键词
- 切换到面板的"文本输入"模式，粘贴文本
- 调用 LLM 提取文本中的关键词
- 提取的关键词自动加入中央区

### F9: 双语界面
- 支持中文和英文界面切换
- LLM 自动根据输入词的语言输出同语言结果

### F10: 布局切换
- 支持 Standard / Elegant 两种布局风格
- 偏好持久化

## 4. 非功能需求

| 需求 | 说明 |
|------|------|
| 响应时间 | LLM 调用不超过 15s，文章生成不超过 10s |
| 数据持久化 | 集合、语言偏好、布局偏好、自动选中设置均存储在 localStorage |
| 前端性能 | JS 包体积 < 300KB（gzip < 100KB） |
| 服务端压缩 | 所有静态资源启用 gzip 压缩 |
| 兼容性 | 现代浏览器（Chrome/Firefox/Safari/Edge 最新版） |

## 5. 用户流程

```
输入种子词 → 探索 → 展示 20 个关联词
  ↓
选中感兴趣的词 → 探索选中 → 词移入中央 + 新 20 个词
  ↓ 反复迭代
中央词积累到满意
  ↓
生成文章 / 保存为集合 / 提取更多词
```
